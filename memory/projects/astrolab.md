# AstroLab
Repository: bimald986-cell/astrolab-v6
Purpose: Vedic astrology calculation, report and Advisor system grounded in deterministic chart evidence.
Durable rules: project astrology settings and engine calculations are authoritative; an LLM must not invent or recalculate placements, dashas, yogas, dignity or transits. Guidance stays reflective rather than deterministic.
Architecture direction: separate canonical evidence/calculation from presentation; reports and Advisor consume the same truth.
Current gate: canonical evidence plus regression verification before release/deployment.
Verify live: open PRs, tests/CI, current main branch and deployed version.
