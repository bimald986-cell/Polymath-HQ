# Elevate Edge — Workable steps (start small)

## Stage 0 — This week

1. Lock brand: **Elevate Edge**.
2. One-line offer: *HR-informed CV & LinkedIn writing so hiring managers see your value quickly.*
3. Canva logo + WhatsApp Business profile.
4. Google Form intake: target role, experience, CV upload, 3 achievements, package.
5. Folder: `Elevate Edge / Clients / Templates / Testimonials`.

**Done =** can take a client without a website.

## Stage 1 — Days 1–30 (revenue first)

| Week | Actions |
|------|--------|
| 1 | 2 sample CVs in your style; price PDF |
| 2 | Message 20 people; LinkedIn tip post |
| 2–3 | 1–2 pilot clients (discount OK for testimonials) |
| 3–4 | Testimonials; full Edge Start pricing |

**Time:** ~5–7 h/week · **Metric:** 2 completed clients + 2 testimonials

## Stage 2 — Days 31–60

- One-page site or Linktree (services, prices, form, Calendly, WhatsApp)
- Personal LinkedIn optimized as Elevate Edge
- Content: LinkedIn 1×/week; short video 2×/week
- Capped free LinkedIn audits → Edge Pro
- Delivery checklist: intake → draft 72h → revision → final PDF

**Metric:** 3–4 paid packages in a month

## Stage 3 — Days 61–90

- Full simple website pages
- Lead magnet (CV checklist) → list
- Stick to tiers; cut unprofitable custom work
- Double the channel that converts; pause the rest

## Weekly rhythm

| Focus | Action |
|-------|--------|
| Outreach | 5 DMs / follow-ups |
| Content | 1 tip post |
| Delivery | Block time when clients active |
| Pipeline | Leads, deadlines, testimonials |

Clients before content when busy.
