# Portfolio Memory Router

Use this file as the small cross-agent entry point for this portfolio.

## Routing rule
1. Read `memory/PORTFOLIO_INDEX.md`.
2. Select only the project or projects relevant to the request.
3. Read only those capsules under `memory/projects/`.
4. Use capsule status as a navigation hint, not proof of live state.
5. Before code changes or claims depending on current state, verify the relevant repo, file, PR, issue, test, CI, or deployment directly.
6. After a verified material milestone or durable decision, update the relevant capsule.
7. Never store secrets, credentials, private keys, or unnecessary sensitive/PII data here.

## Authority
Current repository code/tests and canonical project documents outrank memory capsules when they conflict.

## Token discipline
Keep the index and capsules concise. Detailed history belongs in project docs, issues, Git history, or dedicated references.
